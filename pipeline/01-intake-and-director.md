# 01 需求与导演方案

本阶段的目标不是立刻写 prompt，而是先以视觉导演视角决定“这张动态壁纸应该拍成什么样”。

## 输入

- 用户的角色、题材、参考图、风格或模糊构思；
- 是否已有认可的静态输入图；
- 是否需要循环、静音、1080p、插帧、4K；
- 用户明确的必须保留与禁止内容。

## Agent 动作

1. 判断是从零 T2I，还是用户已有认可图片直接进入 I2V。
2. 先做视觉导演规划，不直接机械扩写 prompt。
3. 设计：
   - 主体姿势、身体朝向、头部和视线；
   - 景别、相机高度、俯仰/侧角、固定焦距；
   - 16:9 构图与视觉重心；
   - 前景/主体/背景层次；
   - 主光、轮廓光、色温和色彩关系；
   - 场景、道具和硬质结构；
   - 后续适合微动画的区域；
   - 必须锁死的区域；
   - 计划中的 I2V 运动系统。
4. 从视频可执行性反向约束静态图：不要为了单帧炫技加入大量重叠肢体、复杂遮挡、强透视手部、难闭合单向粒子或大幅镜头运动。
5. 选择唯一主路线。

## Director Brief

至少输出：

```text
subject:
visual_goal:
pose_and_gaze:
shot_and_camera:
composition_16_9:
lighting_and_color:
scene_and_props:
animation_ready_regions:
static_lock_regions:
forbidden_changes:
planned_motion_for_i2v:
primary_route:
```

## 设计原则

- 静态图必须先好看，但也必须适合作为 I2V 的首帧。
- 发梢、衣摆、飘带等需要运动时，要给它们留出清晰轮廓和空间。
- 水晶、武器、栏杆、建筑、地面等硬质结构优先稳定，不把它们设计成视觉上模糊或交叠严重的形态。
- 动态壁纸默认固定镜头；如果用户没有明确要求，不主动设计推拉摇移。
- 默认只规划 2–3 个主要运动系统，避免 H3 同时重构太多区域。
