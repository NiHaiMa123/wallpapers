# 08 故障与回退

本文件只定义当前生产主流程的故障分类和回退。不要因为某个阶段失败就自动扩展成新的实验路线。

## 通用原则

1. 一次只改变一个主要变量。
2. 保留失败视频、帧目录、报告和参数。
3. 生成错误回到生成阶段；后处理错误回到后处理阶段。
4. 人工 Gate 未完成不是故障，状态应是 `WAITING_FOR_USER_SELECTION`。

## 故障表

| 现象 | 回退 |
|---|---|
| T2I 脸/手/姿势严重错误 | 重新抽静态图，不进入 I2V |
| 静态图漂亮但不适合动画 | 回到 Director Brief，优化遮挡、轮廓或动态预留 |
| 低画质 seed 镜头漂移/动作错误 | 换 seed；必要时单轴修改 motion prompt |
| Turbo/低成本 preview 节点缺失 | 使用仓库已验证的标准低分辨率替代筛选，不自动安装节点 |
| 1080p take 与低画质 seed 行为不同 | 正常高分辨率漂移；重新抽 take 或回 Gate B 换 seed |
| 1080p 身份/解剖/武器错误 | 淘汰 take，不进入逐帧后处理 |
| 1080p 尾部降速/冻结但主体质量可接受 | 进入全帧导出，由用户在 Gate D 决定 keep list |
| 自动速度指标与用户观感冲突 | 以用户最终留帧决定为准，指标保留作证据 |
| 用户 keep list 造成明显位置跳跃 | 警告并展示结果；如用户要修改，返回 Gate D |
| RIFE 鬼影/接缝假溶解 | 回退未插帧候选或调整已验证插帧方案 |
| 超分纹理爬行/halo | 回退 `temporal_safe` 或未超分候选 |
| API 不可达/队列非空 | 不提交第二任务；确认实例和现有队列 |
| RAM 接近熔断 | 接受中断、释放模型、关闭冲突负载；不自动提高阈值 |
| 输入同名不同哈希被拒绝 | 使用唯一文件名，不覆盖已有输入 |
| runner 被中断但服务端仍运行 | 查询队列并回收已有输出或显式中断，不盲目重跑 |

## 需要用户额外授权的操作

以下操作不能因为“继续流程更方便”自动执行：

- 安装新节点或模型；
- 修改 ComfyUI 安装目录或实例；
- 提高 RAM 熔断；
- 删除/覆盖历史文件；
- 切换到仓库未验证的新工作流；
- 运行明确的负对照或边界实验。

## 回退层级

```text
T2I 不合格 -> Director/T2I
低画质 seed 不合格 -> 换 seed / motion prompt 单轴调整
1080p take 不合格 -> 重抽 take；必要时回 Gate B
尾部降速 -> Gate D 人工留帧
RIFE 不合格 -> 回到重建后的未插帧版本
超分不合格 -> temporal_safe / 未超分版本
Final QC 不合格 -> 回到最近能够真正改变该缺陷的阶段
```

不要用插帧、超分、复制帧或编码技巧掩盖身份、解剖或结构性生成错误。
