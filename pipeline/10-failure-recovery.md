# 10 故障与安全降级

## 处理原则

先判断故障属于环境、资源、工作流、提示词、seed、循环还是编码。一次只改变一个主要变量，并保留失败证据。

## 故障表

| 现象 | 分类 | Agent 动作 |
|---|---|---|
| Turbo 报 `MiniMaxH3TurboLoRA` missing | 可选节点缺失 | 不安装；记录后改用 2–3 个标准 draft seed |
| 标准工作流缺核心节点 | 环境阻塞 | `BLOCKED`；列出精确节点，等待用户授权修复环境 |
| API 不可达 | 环境阻塞 | 检查目标实例和端口；不盲目改工作流 |
| 队列非空 | 并发冲突 | 等待或报告现有任务；不提交第二个任务 |
| RAM 接近或达到熔断 | 资源失败 | 接受中断，调用 `/free`，关闭冲突负载，保留阈值，从上一档继续 |
| 队列已空但空闲 RAM 仍接近熔断 | 上次任务未卸载模型 | 先 `POST /free`，等到 RAM 降下来再提交；不要提高熔断线 |
| Final 很慢但资源稳定 | 正常长任务 | 看守并定期报告，不因耗时自动中断 |
| 同 seed 跨会话不同 | 可复现性边界 | 重新视觉验收，不引用旧会话结论 |
| 更严 prompt 仍运动过大 | seed 倾向 | 停止堆词，保持 prompt 换 seed |
| 脸、手、肢体或道具错误 | 生成失败 | 淘汰 seed；不用插帧、超分或融合修复 |
| 中段突然过曝 | seed/提示词失败 | 淘汰或单轴调整光效，再做对照 |
| 末帧闭眼或动作卡住 | 时间设计失败 | 改成一次短暂早期事件或换 seed，重跑 long draft |
| 首尾画面接近但边界有顿感 | 末端停死或首尾余速不匹配 | 不要再把末端收到 0；改时间弧让片头片尾余速同量级，使用 LoopLock 重跑 long draft |
| 落花、烟雾或粒子在边界跳回 | 单向事件不闭合 | 冻结该元素或改为局部闭合轨迹后重新生成 |
| AI 4K 纹理爬行 | 超分失败 | 回退 `temporal_safe` |
| 系统 Python 报缺少 `av` | 运行时错误 | 使用 ComfyUI venv Python，不安装到系统 Python |
| 输入同名不同哈希被拒绝 | 防覆盖生效 | 改用唯一文件名，不覆盖共享 input 中已有文件 |
| ComfyUI 提交报 400/`Invalid video file` | 输入目录错位 | 确认 staging 进的是 serving 实例的输入目录（当前 `ComfyUI-Shared\input`），读该实例 `logs/comfyui.log` 的服务端确切原因 |
| 本地 runner 被杀但队列仍在跑 | 跟踪中断而非任务中断 | 查 `/queue` 确认服务端任务状态：跑完则回收输出补报告；不需要则显式调 `/interrupt`；不默默重跑占队列 |

## 回退层级

```text
final 失败 -> 保留 long_draft
long_draft 失败 -> 回到 draft 或 seed 筛选
draft 失败 -> 修改单一 prompt 轴或换 seed
Turbo 缺失 -> 标准 draft 小规模筛选
Loop 失败 -> 收紧周期动作，禁止末段停死，匹配片头片尾余速，使用 LoopLock 重新生成母版
4K 失败 -> 交付已通过的原始循环
```

## 何时请求用户授权

只有完成任务确实需要以下扩展时才停下请求：

- 安装缺失节点或模型；
- 修改 ComfyUI 安装目录或实例；
- 提高熔断线或运行负对照边界 profile；
- 删除或覆盖历史文件；
- 改用仓库未验证的新工作流。

## 故障报告

报告精确错误、失败发生阶段、是否开始推理、是否产生可用输出、保存了哪些证据、安全降级路线，以及继续工作需要的授权。不要只写“运行失败”。
